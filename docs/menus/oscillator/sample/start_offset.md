Shifts where the sample starts playing. Full scale (+/-512) moves the start by one whole sample length; negative values start earlier. It is a patchable parameter, so it can be parameter-locked per step, automated, or modulated by velocity, LFOs and envelopes.

With offset wrap on, the playback window rotates around the whole sample. If that pushes the loop across the end of the sample, the voice plays from the loop start to the sample end, then from the sample start to the loop end, and repeats. Changing the offset while a looping (LOOP or STRETCH) note is held moves playback straight away.
